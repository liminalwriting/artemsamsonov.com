# Сайт Артёма Самсонова

[artemsamsonov.com](https://artemsamsonov.com) — личный сайт и портфолио: главная с опытом и менторством плюс кейсы и статьи.

Сайт слеплен с помощью Pug + SCSS + Webpack. Никакого React, TypeScript и бэкенда здесь нет и не планируется: на выходе — обычная статика.

## Если вдруг захотелось запустить локально

1. Установить пакеты: `yarn install`
2. Поднять дев-сервер: `yarn run devserver`
3. Ну или отключить дома интернет и собрать production-версию статики: `yarn run build`
4. Обновить SEO-файлы (`sitemap.xml`, `robots.txt`, `manifest.json`): `npx gulp seo`

Собранная статика лежит в `docs/` — именно она уезжает на прод, поэтому после осмысленных правок её тоже коммитим.

## Что где лежит

```
src/
  pages/<slug>/<slug>.pug   одна папка = одна страница (→ docs/<slug>.html)
  components/<name>/        Pug-миксин + SCSS рядом
  scss/                     цвета, сетка, типографика, стили статей
  js/index.js               аналитика и мелкие эффекты
  img/ video/ fonts/        ассеты, копируются в docs/ как есть
docs/                       результат сборки
webpack/                    модули конфига
gulpfile.js                 SEO-задачи
```

Правки делаем в `src/`, а не в собранном `docs/`.
