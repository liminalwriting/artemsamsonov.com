# Как создать кейс из шаблона

Исходный шаблон лежит в `src/pages/template-case/template-case.pug`. Он содержит hero, теги, интерактивное сравнение «до/после», текстовые секции и карточки результатов.

## 1. Скопируй шаблон

Создай папку нового кейса в `src/pages/`. Название папки станет адресом страницы:

```text
src/pages/my-new-case/
```

Скопируй в неё `template-case.pug` и переименуй файл так же, как папку:

```text
src/pages/my-new-case/my-new-case.pug
```

Имена обязаны совпадать. Webpack автоматически создаст `built/my-new-case.html`.

## 2. Обнови метаданные

В вызове `+head(...)` замени:

- title;
- description;
- URL превью для Open Graph;
- при необходимости тип страницы.

Перед публикацией удали строку:

```pug
meta(name="robots" content="noindex, nofollow")
```

Она защищает незаполненный шаблон от индексации. Сам `template-case.html` дополнительно исключён из sitemap в `gulpfile.js`; новый кейс после сборки попадёт в sitemap автоматически.

## 3. Настрой hero

Замени фон в атрибуте `--article-hero-image`:

```pug
div.article__hero(style="--article-hero-image: url(img/my-new-case-hero.jpg)")
```

Файл положи в `src/img/`. В hero также замени:

- `h1` — название продукта или проекта;
- `.article__annotation` — измеримый результат в одном предложении;
- теги — роль и основные виды работы.

Синтаксис тега:

```pug
+tag('Название', 'S', 'light')
```

Доступные размеры: `S`, `M`. Доступные цветовые режимы: `light`, `dark`.

## 4. Настрой сравнение «до/после»

Первое изображение — интерфейс до изменений, второе — после:

```pug
img.article__compare-before(src="../../img/my-case-before.jpg" alt="Интерфейс до изменений")
img.article__compare-after(src="../../img/my-case-after.jpg" alt="Интерфейс после изменений")
```

Оба файла положи в `src/img/`. Желательно использовать изображения одинаковой ширины и близких пропорций.

Подписи «После» и «До» находятся над изображениями. Шторка поддерживает мышь, touch и клавиатуру, а после загрузки коротко двигается, подсказывая механику. При `prefers-reduced-motion` intro-анимация отключена.

Кнопка «Развернуть на всю высоту» рассчитывает полную высоту по первому изображению. Если меняешь разметку сравнения, сохраняй классы `.article__compare-before`, `.article__compare-after`, `.article__compare-handle` и `.article__compare-toggle` — на них завязана логика из `src/js/index.js`.

Если сравнение не нужно, удали целиком:

- `.article__compare-heading`;
- `.article__compare`.

## 5. Заполни структуру кейса

Шаблон предлагает последовательность:

1. Контекст — продукт, аудитория и исходная ситуация.
2. Проблема — что не работало для пользователей и бизнеса.
3. Решение — этапы исследования и проектирования.
4. Подробности — отдельные изменения через `+skillCard`.
5. Результаты — метрики и бизнес-эффект.

Удаляй ненужные секции и добавляй новые по смыслу. Не сохраняй плейсхолдеры в опубликованном кейсе.

## 6. Собери и проверь

```bash
yarn run build
npx gulp seo
```

Проверь:

- страницу `built/my-new-case.html`;
- desktop и mobile;
- работу шторки и кнопки разворачивания;
- пути ко всем изображениям;
- title, description и Open Graph;
- отсутствие `noindex`;
- наличие нового URL в `built/sitemap.xml`.

Правки вноси в `src/`. Собранные файлы в `built/` вручную не редактируй.
